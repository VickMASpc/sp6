# Model Atlas

A complete, interactive release-day model comparison dashboard for September 29, 2026.

- GPT-6.1 Sol, GPT-6 Sol, Luna and Astra; Claude Sonnet and Opus 5.5.
- 32 current effort variants plus six historical Sonnet 5 variants.
- AA Intelligence Index v4.3.2, 18 benchmark fields, capability indexes, benchmark-specific economics, cost components, token usage, and latency distributions.
- Ten official OpenAI launch chart datasets, presented separately from AA.
- Model filters, effort selectors, head-to-head presets, heatmaps, cache calculator, CSV and JSON exports.

Static HTML/CSS/ES modules; no build step, external CDN, analytics, keys, or backend.

The snapshot is fixed. Sources and methodology are accessible in the dashboard. Sonnet 5.5 Low's prior complete snapshot is isolated from current-data plots because the refreshed AA result is incomplete.
